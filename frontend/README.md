# Potato Eyes 프런트엔드

iOS 기준 Expo / React Native UI입니다. `screens`의 네 화면을 `App.js` 하단 탭으로 전환합니다. 기본 화면은 뉴스입니다. 데이터는 모두 예시이며 백엔드와 위치 서비스는 연결하지 않았습니다.

```sh
cd frontend
npm install
npm start
```

iPhone에서 Expo Go로 QR 코드를 스캔하세요. iOS 시뮬레이터 실행은 macOS와 Xcode가 필요합니다. Windows에서는 실제 iPhone으로 확인할 수 있습니다.

컴퓨터 브라우저 미리보기: npm run web (PowerShell에서는 npm.cmd run web). 웹 미리보기는 iOS와 일부 글꼴 및 기본 동작이 다를 수 있습니다.
