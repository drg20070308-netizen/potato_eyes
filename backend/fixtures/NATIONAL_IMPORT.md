# 전국 민방위 대피시설 자료

원본: 사용자가 공공데이터포털의 공식 배포처에서 내려받아 제공한 `민방위대피시설.csv`.
제공기관: 행정안전부. 원본 페이지: https://www.data.go.kr/data/15044951/fileData.do
전국 표준자료 안내: https://www.data.go.kr/data/15021098/standard.do
파일 배포처: https://file.localdata.go.kr/file/civil_defense_shelter_info/info
이용허락범위: 제한 없음(공공데이터포털 표기).

원본 18,843건 중 운영상태가 사용중이고 해제일자가 없는 17,239건을 수록했습니다. 사용중지·일시중지 등 1,604건은 제외했습니다. 17개 시도 표기가 확인됐으며, EPSG4326 위경도가 없는 8건은 지역 목록에는 포함하되 좌표 확인 실패 시 반경 결과에서 제외합니다. 개인 담당자 연락처는 저장하지 않습니다. 원본 SHA-256 및 수집 시점은 national-official-shelters.json에 포함합니다.

현재는 제공받은 파일의 스냅샷입니다. 실시간 개방·수용 여유와 제공기관의 누락 여부까지 보장하지 않습니다. 전국 공표 자료 전체를 검색하며 현재 현장 상태를 조사한 전수조사는 아닙니다.

자료 갱신: 저장소 루트에서 `python backend/scripts/import-national.py 새원본.csv` 실행 후 검증·커밋·재배포합니다. 열 매핑, 운영 상태, 해제일자, 시도 수와 좌표 범위를 검사합니다. EPSG5179 등 투영 X/Y를 위경도로 오인하지 않습니다.
