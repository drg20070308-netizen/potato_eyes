# 부산 공식 민방위 대피시설 자료

확인일: 2026-10-30. 사하구 80곳, 사상구 93곳으로 총 173곳. 원본 페이지에 게시된 목록을 그대로 추출한 스냅샷이며 지자체의 최신 변경 반영을 보장하지 않습니다. 시설명/행정동/공개 주소/공개 좌표만 사용하고 담당자 개인정보는 포함하지 않았습니다.

사하구청: https://www.saha.go.kr/portal/contents.do?mId=0409020000
사상구청: https://www.sasang.go.kr/index.sasang?menuCd=DOM_000000108011001000

갱신: 저장소 루트에서 python backend/scripts/import-busan.py 실행 후 변경을 검토하고 커밋합니다. 사하구 좌표는 서버에서 공식 도로명 주소로 카카오 주소 변환 API를 조회하여 메모리에 보관합니다. 좌표 확인 실패 시 지역 목록에는 시설을 유지하고 반경 검색에서만 제외합니다. 실제 개방 상태/수용 가능 여부는 확인되지 않았습니다. 수록 범위 밖은 기존 카카오 검색을 사용하므로 전국 공식 전수 목록이 아닙니다.
